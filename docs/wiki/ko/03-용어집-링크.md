# 용어집 링크

화면에서 용어에 마우스를 올리면 뜻풀이가 나옵니다. 전체 목록은 앱의 `/glossary`(용어집)에서 찾고, 원본은 저장소의 `glossary/*.yaml`입니다. MCP 도구 `lookup_term`으로도 조회됩니다.

## 이 안내서가 쓰는 말

| 용어 | 뜻 (한 줄) |
|---|---|
| 투자 주체 | 투자가 실행되는 주체이자 통로(직접 투자, SPC, 지주회사, 합작법인 등). S10에서 정함 |
| 설립 법인 형태 | 그린필드 신규 설립 시 사업을 담을 법인의 형태. S10에서 그린필드의 투자 주체 자리에 쓰는 말 |
| 신규 사업 | 이 시스템이 검토하는 사업(그린필드와 브라운필드 모두). 용어집 등록 없음 |
| 인력/조직 계획 | 실사 범위의 한 항목(사람과 조직 계획). 용어집 등록 없음 |
| 법인 투자심의위원회 | 개별 계열사 단위의 투자 승인 심의. 그룹 심의의 선행 조건 |
| 그룹 투자심의위원회 | 그룹 차원의 심의(포트폴리오 정합성, 자본 배분 우선순위) |
| 투자심의 자료 | 투자 구조, 채택된 사업성 분석, 실사 발견, 등급 제안을 한 묶음으로 정리한 위원회 자료. 결재가 아님 |
| 종합 등급 | 6개 차원 평가의 종합(RAG). 자료 신뢰도가 상한을 정하고, 제안일 뿐 승인은 사람 |
| 중점 투자 분야 | 그룹이 우선하는 투자 분야. 용어집 등록 없음 |
| 현상 유지안 | 아무것도 하지 않을 때의 기준안. 용어집 등록 없음 |

> [!NOTE]
> 풀이는 `glossary/*.yaml`의 `definition_ko`를 줄인 것입니다. 정의의 기준은 앱 용어집입니다. 등록이 없는 네 용어(신규 사업, 인력/조직 계획, 중점 투자 분야, 현상 유지안)는 용어집 등록 여부를 확인해야 합니다(결함 기록 참고).

## 화면에 남은 영어 용어

`Long List`, `Short List`, `PROPOSAL`, `Pre-FS`, `Greenfield`, `Brownfield` 같은 영어 표기가 화면에 남아 있습니다. 이 안내서는 화면 표기를 그대로 따옵니다.
