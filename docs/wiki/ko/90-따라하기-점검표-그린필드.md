# 따라하기 점검표: 그린필드 길 처음부터 끝까지

**목적** — 사람 검토자가 그린필드 안건 하나를 S1부터 S12까지 걸어 보며, 안내서대로 화면이 되는지 확인합니다.  **누가/언제** — 안내서 검수자, 처음 쓰는 프로젝트 리드. 한 번에 한 칸씩 체크하세요.  **사전 조건** — 로그인 계정, 데모 안건(`S1-S12 데모 Greenfield 기회`/프로젝트 `DEMO-GF`) 또는 연습용 새 안건.

> [!NOTE]
> 데모 자료로 걸을 때는 **읽기 전용**으로 읽기만 합니다. (쓰기) 표시가 있는 칸은 연습용 새 안건에서만 하세요. 막히면 칸 옆에 "막힘" 메모를 적고 [81-문제-해결](81-문제-해결.md)을 보세요. 안내서와 화면이 다르면 그 쪽 이름과 화면 글자를 적어 알려 주세요.

## 0. 시작 ([01-시작하기](01-시작하기.md))

- [ ] `아이디`와 `비밀번호`로 로그인했다.
- [ ] (첫 로그인이면) `비밀번호 변경`을 끝냈다.
- [ ] 검토/안건 보드에서 필터 `그린필드`를 눌러 그린필드 카드(`DEMO-GF`)가 보이는 것을 확인했다.
- [ ] 보드 카드 아래 `사업 기회 보기`로 안건 개요를 열었다.

## 1. 공통 단계 S1~S3

- [ ] S1 ([20-공통-S1-시장분석](20-공통-S1-시장분석.md)): `분석 대상 산업`에서 산업 한 건을 열어 `기준 시장규모 (2026)`와 `데이터 신뢰도 등급`을 읽었다.
- [ ] S2 ([21-공통-S2-기회-발굴](21-공통-S2-기회-발굴.md)): 기회 퍼널에서 `매력도`와 `시너지` 표지(`제안`/`권고(미확정)`/`확정`)를 구분해 읽었다.
- [ ] S3 ([22-공통-S3-시너지-전략적-적합성](22-공통-S3-시너지-전략적-적합성.md)): `이 딜만`/`전체`를 바꿔 보고 `그룹·계열사 프로파일`을 열어 보았다.

## 2. 갈림길 S4 ([23-공통-S4-진출방식-결정](23-공통-S4-진출방식-결정.md))

- [ ] `진출방식 추천` 카드가 AI 제안임을 확인했다.
- [ ] `결정` 탭에서 `트랙`이 `Greenfield — 자체 역량으로 진출`인지, `라우트 (선택)`이 비어 있어도 되는지 확인했다.
- [ ] `결정 이력`을 열어 근거와 검토한 대안을 읽었다.
- [ ] (쓰기, 연습 안건) **저장**과 **결정**의 차이를 이해하고 사람(리드)만 **결정**을 누른다는 것을 확인했다.
- [ ] 번호 띠에서 6 `대상 후보 발굴`, 7 `대상 선정`이 쓰지 않는 단계로 표시되는 것을 확인했다.

## 3. 그린필드 단계 S5 ([40-그린필드-S5-자체-진출](40-그린필드-S5-자체-진출.md))

- [ ] 역량 격차, 범위 패널, 진출전략 권고를 읽었다.
- [ ] 부지, 인허가, 인센티브, 지역 협력 화면([그린필드 길](10-그린필드-여정.md) 참고)을 열어 보았다.
- [ ] 인허가(운영하게 해 줌)와 인증(판매하게 해 줌)이 다른 것임을 말할 수 있다.

## 4. 사업성 분석 S8 ([30-공통-S8-사업성-분석](30-공통-S8-사업성-분석.md), [41-그린필드-S8-사업성-분석](41-그린필드-S8-사업성-분석.md))

- [ ] 위쪽 탭에 `대상 비교·선정`이 없고 대상이 하나인 것을 확인했다.
- [ ] `시나리오 비교`에서 `기본(Base)`, `상승(Upside)`, `하락(Downside)`의 NPV·IRR을 읽었다.
- [ ] `WACC` 탭에서 `현재 확정값`의 출처(`default` 등)를 확인했다.
- [ ] 채택은 **결정 기록 (사람)**으로 사람이 한다는 것을 확인했다.
- [ ] 게이트 `FS` 결정 버튼이 안건 개요에 있는 것을 찾았다.

## 5. 실사 S9 ([31-공통-S9-실사](31-공통-S9-실사.md), [42-그린필드-S9-실사](42-그린필드-S9-실사.md))

- [ ] `실사 대상` 줄이 "지정된 회사가 없습니다 … 프로젝트 기준으로 실사합니다."인 것을 확인했다.
- [ ] 분야 탭 일곱 개와 `보기`의 `판정 대기만`, `미충족만`을 눌러 보았다.
- [ ] 판정 버튼 **충족**, **미충족**, **해당없음**, **면제 요청·연결**의 뜻을 말할 수 있다.
- [ ] `판정 완료 · 필수 미충족 0건`이 완료 조건임을 확인했다.

## 6. 투자구조 S10 ([32-공통-S10-투자심의-전](32-공통-S10-투자심의-전.md), [43-그린필드-S10-실행-기준선](43-그린필드-S10-실행-기준선.md))

- [ ] 화면 제목이 `설립 구조 — 설립 법인 형태·…`인 것을 확인했다.
- [ ] `투자구조 가설`의 네 축(절세, 책임 격리, 재무 레버리지, 엑싯)과 `4축 검토 완료` 표지를 읽었다.
- [ ] `설비투자 집행 단계` 탭과 `자금조달 계획`(조달처와 사용처의 합계)을 확인했다.
- [ ] 실행 기준선 확정은 사람이 한다는 것을 확인했다.

## 7. 투자심의와 설립 실행 S11 ([33-공통-S11-투자심의와-실행](33-공통-S11-투자심의와-실행.md), [44-그린필드-S11-설립-실행](44-그린필드-S11-설립-실행.md))

- [ ] `투자심의 자료`와 `종합 등급`(`AI 추천 (승인 아님)`)을 읽었다.
- [ ] `법인 투자심의위원회` → `그룹 투자심의위원회` 순서와 `결정 이력`을 확인했다.
- [ ] `설립 실행 — 5단계`가 몇 단계까지 끝났는지(예: `5/5`) 찾았다.
- [ ] 단계 완료와 재개는 사람만 한다는 것을 확인했다.

## 8. 사후 관리 S12 ([34-공통-S12-사후-관리](34-공통-S12-사후-관리.md), [45-그린필드-S12-사후-관리](45-그린필드-S12-사후-관리.md))

- [ ] 분기별 `스코어카드 트렌드`에서 `목표 달성`, `이탈`, `근거 부족` 건수를 읽었다.
- [ ] `실행 기준선 대비 차이`를 찾았다.
- [ ] **프로젝트 종료…**는 선결조건 확인 뒤 사람이 기록한다는 것을 확인했다.
