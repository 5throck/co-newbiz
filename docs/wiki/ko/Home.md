# 신규사업 검토 사용자 안내서

이 안내서는 화면에서 무엇을 어디서 누르는지를 사용자 여정 순서대로 설명합니다. 규정과 절차의 내용은 `procedures/*.yaml`이 기준이고, 이 안내서는 "어디를 눌러 하는가"만 다룹니다. 역할 중심의 기존 설명은 [업무 매뉴얼](../../manuals/business-manual_ko.md), [관리자 매뉴얼](../../manuals/admin-manual_ko.md), [운영 매뉴얼](../../manuals/operations-manual_ko.md)에 있습니다.

> [!NOTE]
> 이 시스템은 의사결정 지원 도구입니다. 게이트 승인, 투자 결정, 진출방식(트랙) 결정은 사람만 기록합니다. AI는 초안과 제안만 만듭니다. 안내서의 화면 그림은 모두 **데모 자료**로 찍었습니다. 이름과 숫자는 내 화면과 다릅니다.

## 처음이라면

1. [01-시작하기](01-시작하기.md): 로그인부터 데모 안건 읽기까지 15분.
2. [04-역할별-시작-페이지](04-역할별-시작-페이지.md): 내 역할(분석가, 프로젝트 리드, 투자심의 위원, 열람자, 운영자)에 맞는 읽기 순서.
3. 막히면 [81-문제-해결](81-문제-해결.md)과 [80-자주-묻는-질문](80-자주-묻는-질문.md).

## 그린필드와 브라운필드 한눈에 비교

두 길은 S4에서 갈라지고 S8에서 다시 만납니다.

| | 그린필드 (자체 진출) | 브라운필드 (결합 진출) |
|---|---|---|
| 뜻 | 우리 역량으로 새로 세워서 들어감 | 기존 기업·자산과 결합해서 들어감 |
| 길 | S1~S4 → **S5** → S8~S12 | S1~S4 → **S6~S7** → S8~S12 |
| S4에서 기록하는 것 | `트랙`을 Greenfield로(`라우트`는 선택) | `트랙`을 Brownfield로 + `라우트`(M&A, JV 등, 필수) |
| 쓰지 않는 단계 | S6, S7 | S5 |
| S5~S7에서 하는 일 | 역량 격차, 부지, 인허가, 인센티브 | 후보군 기준, 긴 목록, 짧은 목록, 대상 선정 |
| S8 사업성 | 대상 하나(단일 범위) | 대상별 분석 + 사람이 대상 선정 |
| S9 실사 | 지정 회사 없이 프로젝트 기준 | 선정 대상 기준 + M&A 6대 검증, 특수 주제 |
| S10 투자구조 | `설립 법인 형태`, 실행 기준선, 투자 분할 집행 | `투자 주체`, 거래 구조, `차입·여신` |
| S11 투자심의 뒤 | 설립 실행 5단계 | PMI 킥오프(클로징) |
| S12 사후 관리 | 실행 기준선 대비 차이 | PMI(핵심 인력, 시너지 인증) |
| 길 안내 | [10-그린필드-여정](10-그린필드-여정.md) | [11-브라운필드-여정](11-브라운필드-여정.md) |
| 처음부터 끝까지 | [90-따라하기-점검표-그린필드](90-따라하기-점검표-그린필드.md) | [91-따라하기-점검표-브라운필드](91-따라하기-점검표-브라운필드.md) |

브라운필드는 곧 인수합병(M&A)이라는 뜻이 아닙니다. 화면 안내문에도 "Brownfield ≠ M&A"라고 적혀 있으며, M&A, JV, 전략적 투자 등 라우트 유형을 따로 고릅니다.
