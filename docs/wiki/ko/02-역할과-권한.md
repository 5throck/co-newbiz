# 역할과 권한

**목적:** 누가 무엇을 할 수 있고 어떤 일은 사람만 할 수 있는지 한눈에 본다.

> [!NOTE]
> 안내서의 화면 그림은 모두 데모 자료다. 이름과 숫자는 내 화면과 다르다.

## 역할

| 역할 | 하는 일 | 못 하는 일 |
|---|---|---|
| `admin` (운영자) | 사용자·기준 정보·데이터 출처·일정·시스템 모드 관리 | 프로젝트 안의 결정을 대신 기록하지 않는다 |
| 프로젝트 `lead` (프로젝트 리드) | 안건 책임, 진출방식 결정, 대상 선정, 기준선 확정, 게이트 제출 | 없음 |
| 프로젝트 `member` (분석가) | 분석 입력, AI 초안 요청, 실사 결과 기록 | 사람만 하는 결정은 제안까지만 |
| `viewer` (열람자) | 상태·보고서 읽기 | 쓰기 전부 |
| 위원회 검토자 권한(`법인 투자심의위원회 검토자`, `그룹 투자심의위원회 검토자`) | 다른 사람이 기록한 법인·그룹 GO를 두 번째로 확인, 조건 해소, 면제 승인, 그룹 위원회 검토자는 중단 조건 예외 발급 | 직접 기록한 GO를 스스로 확인. 이 권한은 역할 위에 관리자가 따로 부여하며 자료 열람 권한을 주지 않는다 |

AI 에이전트는 자기 계정이 없다. 에이전트는 호출한 사람의 권한을 그대로 물려받는다. 그래서 사람이 볼 수 없는 프로젝트는 에이전트도 볼 수 없다.

## 사람만 할 수 있는 일

| 일 | 어디서 | 화면 표시 |
|---|---|---|
| 진출방식(트랙·라우트) 결정 | S4 `결정` 탭의 `결정` 버튼 | "진출방식 제안 (사람이 확정)" |
| 대상 선정 (브라운필드) | S7 | 작성 예정(구간 2/3) |
| 게이트 승인과 투자 결정 | 각 단계의 결정 기록 상자, 투자심사(S11) 쪽 | `결정` 버튼. [33-공통-S11-투자심의와-실행](33-공통-S11-투자심의와-실행.md) |
| 법인·그룹 GO의 두 번째 검토 | S11 결정 기록 아래 `이 GO의 두 번째 검토` | GO를 기록한 사람과 다른 사람, 위원회 검토자 권한 필요 |
| 단계 완료와 다시 열기 | 단계 화면의 완료/재개 조작 | 작성 예정(구간 2/3) |
| 가중평균자본비용(WACC) 확인 | 프로젝트 WACC 화면 | 확정하기 전에는 `잠정 할인율`이고 `FS` GO가 막힌다. [30-공통-S8-사업성-분석](30-공통-S8-사업성-분석.md) |
| 면제 승인 | S9 면제 관리 | 요청한 사람과 다른 사람, 위원회 검토자 권한 필요, 기간 최대 90일 |

AI가 만든 것은 모두 **제안**이다. 화면 문구도 "최종 결정은 사람이 기록합니다"라고 알려 준다.

## 검토 결과 읽는 법: 세 구역

각 단계 화면의 `3단계 검토`는 "AI 1차(결정론 검사) → AI 2차(다른 영역 교차 검토) → 사람 최종"의 순서다. 결과는 세 구역으로 나뉜다.

| 구역 | 뜻 |
|---|---|
| `확인됨` | AI가 근거와 함께 확인한 것 |
| `확인하지 못함` | AI가 확인하지 못한 것. 침묵을 승인으로 읽지 않는다 |
| `판단 필요` | 사람이 판단할 것 |

화면에 "검토 결과는 승인·통과 표시가 아닙니다"라고 적혀 있다. 규정, 게이트 승인, 투자 결정, 보안·개인정보 모델은 AI 검토만으로 통과할 수 없다.

## 자주 하는 실수

| 오해 | 바른 읽기 |
|---|---|
| 열람자 계정으로 `저장`이 안 된다고 오류로 여기는 것 | 권한 문제다 |
| AI 추천(`추천: Brownfield` 등)을 결정으로 착각하는 것 | 추천은 제안이다 |
