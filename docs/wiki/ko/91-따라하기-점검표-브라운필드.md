# 따라하기 점검표: 브라운필드 길 처음부터 끝까지

**목적** — 사람 검토자가 브라운필드 안건 하나를 S1부터 S12까지 걸어 보며, 안내서대로 화면이 되는지 확인합니다.  **누가/언제** — 안내서 검수자, 처음 쓰는 프로젝트 리드. 한 번에 한 칸씩 체크하세요.  **사전 조건** — 로그인 계정, 데모 안건(`S1-S12 데모 Brownfield 기회`/프로젝트 `DEMO-S1-S12`) 또는 연습용 새 안건.

> [!NOTE]
> 데모 자료로 걸을 때는 **읽기 전용**으로 읽기만 합니다. (쓰기) 표시가 있는 칸은 연습용 새 안건에서만 하세요. 막히면 칸 옆에 "막힘" 메모를 적고 [81-문제-해결](81-문제-해결.md)을 보세요. 안내서와 화면이 다르면 그 쪽 이름과 화면 글자를 적어 알려 주세요.

## 0. 시작 ([01-시작하기](01-시작하기.md))

- [ ] 로그인하고 (첫 로그인이면) 비밀번호를 바꿨다.
- [ ] 검토/안건 보드에서 필터 `브라운필드`를 눌러 브라운필드 카드(`DEMO-S1-S12`)가 보이는 것을 확인했다.
- [ ] 보드 카드 아래 `사업 기회 보기`로 안건 개요를 열었다.

## 1. 공통 단계 S1~S3

- [ ] S1 ([20-공통-S1-시장분석](20-공통-S1-시장분석.md)): `데이터 신뢰도 등급`과 `체인 등급`이 서로 다른 지표임을 확인했다.
- [ ] S2 ([21-공통-S2-기회-발굴](21-공통-S2-기회-발굴.md)): 기회 상세에서 `기회·위험 요인`과 `비즈니스 모델 검토` 탭을 열어 보았다.
- [ ] S3 ([22-공통-S3-시너지-전략적-적합성](22-공통-S3-시너지-전략적-적합성.md)): `시너지 분석 목록`에서 `이 딜만`/`전체`를 바꿔 보았다.

## 2. 갈림길 S4 ([23-공통-S4-진출방식-결정](23-공통-S4-진출방식-결정.md))

- [ ] `결정` 탭에서 `트랙`이 `Brownfield — 기존 기업·자산과 결합`이고 `라우트`(필수)가 채워져 있는지 확인했다.
- [ ] 브라운필드가 M&A와 같은 말이 아님을 말할 수 있다.
- [ ] 번호 띠에서 5 `자체 진출`이 쓰지 않는 단계로 표시되는 것을 확인했다.

## 3. 대상 찾기와 고르기 S6~S7 ([50-브라운필드-S6-대상-후보-발굴](50-브라운필드-S6-대상-후보-발굴.md), [51-브라운필드-S7-대상-선정](51-브라운필드-S7-대상-선정.md))

- [ ] 후보군 기준과 긴 목록(`Long List`)을 읽었다.
- [ ] 스크리닝과 짧은 목록(`Short List`)을 읽었다.
- [ ] 대상 선정은 사람(리드)이 기록한다는 것을 확인했다.
- [ ] 게이트 `대상 선정` 결정이 안건 개요에 표시되는 것을 확인했다.

## 4. 사업성 분석 S8 ([30-공통-S8-사업성-분석](30-공통-S8-사업성-분석.md), [52-브라운필드-S8-사업성-분석](52-브라운필드-S8-사업성-분석.md))

- [ ] 위쪽 탭에 `대상 비교·선정`이 있는 것을 확인했다.
- [ ] `재무분석` 탭의 `연결된 대상 회사`와 `동기화 전` 표지를 확인했다.
- [ ] `시나리오 비교`에서 NPV·IRR을 읽고, 채택은 사람이 **결정 기록 (사람)**으로 한다는 것을 확인했다.

## 5. 실사 S9 ([31-공통-S9-실사](31-공통-S9-실사.md), [53-브라운필드-S9-실사](53-브라운필드-S9-실사.md))

- [ ] `실사 대상` 줄에 선정한 대상 회사와 `S8 선정 대상 · 게이트 기준`이 보이는 것을 확인했다.
- [ ] 분야 탭 아홉 개 중 `M&A 6대 검증(브라운필드 타당성)`과 `M&A 특수 주제`를 열었다.
- [ ] 고객 지배권 변경 조항, 보상 균등화, 인터뷰 화면을 열어 보았다.
- [ ] 여섯 가지 필수 검증이 모두 기록되어야 한다는 것을 53쪽에서 확인했다.

## 6. 거래 구조 S10 ([32-공통-S10-투자심의-전](32-공통-S10-투자심의-전.md), [54-브라운필드-S10-거래-구조](54-브라운필드-S10-거래-구조.md))

- [ ] 화면 제목이 `S10 투자구조 설계 — 투자 주체·4축 검토·자금조달`인 것을 확인했다.
- [ ] `투자구조 가설`에서 `투자 주체`, 지분, 지급 수단과 `4축 검토 완료`를 읽었다.
- [ ] `차입·여신` 탭에서 차입 기록과 커버넌트 여력을 읽었다.

## 7. 투자심의와 클로징 S11 ([33-공통-S11-투자심의와-실행](33-공통-S11-투자심의와-실행.md), [55-브라운필드-S11-클로징](55-브라운필드-S11-클로징.md))

- [ ] `투자심의 자료`와 `종합 등급`(`AI 추천 (승인 아님)`)을 읽었다.
- [ ] 법인 → 그룹 순서와 `결정 이력`을 확인했다.
- [ ] 인수에는 `설립 실행 5단계`가 적용되지 않는다는 안내와 `PMI 킥오프` 기록을 찾았다.

## 8. 통합과 사후 관리 S12 ([34-공통-S12-사후-관리](34-공통-S12-사후-관리.md), [56-브라운필드-S12-통합-PMI](56-브라운필드-S12-통합-PMI.md))

- [ ] `PMI` 탭의 `핵심인력 잔존`과 `시너지 인증`을 읽었다.
- [ ] 분기별 `스코어카드 트렌드`를 읽었다.
- [ ] **프로젝트 종료…**는 선결조건 확인 뒤 사람이 기록한다는 것을 확인했다.

## 마무리

- [ ] 막힌 칸의 쪽 이름과 화면 글자를 정리해 알렸다.
- [ ] 안내서 각 쪽 끝 "스스로 확인하기" 질문에 답할 수 있다.
- [ ] 그린필드 길도 걸어 보려면 [90-따라하기-점검표-그린필드](90-따라하기-점검표-그린필드.md)로 가세요.
