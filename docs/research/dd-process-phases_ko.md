# 리서치 노트 — M&A 실사 단계·타임라인 표준 관행

> **언어**: [English](dd-process-phases.md) · **한국어**

> 🌐 외부 참고 자료. 조사일: 2026-09-05. S9 실사 트랙(Brownfield/Greenfield)의 단계 구분을 업계 표준과 비교하기 위한 참고.

## 표준 관행

1. **6단계 표준 흐름**: Pre-LOI 스크리닝(제한된 정보로 딜 가치 판단) → LOI 체결·exclusivity 확보 →
   confirmatory 실사(가장 방대한 단계 — QoE·법무·운영·고객 검증) → 딜 조건 협상(실사 발견을
   가격조정·인뎀니티·에스크로로 전환) → pre-closing 최종 확인 → closing (dealroom, Peony)
2. **confirmatory 단계가 실사의 핵심**: 대부분의 발견사항은 LOI 이후 exclusivity 기간에
   전체 data room이 열리면서 나온다 — 이 단계 전에는 정보가 제한적이라 판단이 예비적일 수밖에 없다
3. **표준 소요기간**: LOI부터 종결까지 통상 30~45영업일(중견시장 기준), 복잡한 딜은 90일 이상
4. **종결 후에도 리스크 존재**: 운전자본 정산(working capital true-up), 만료 예정 계약 등은
   종결 후에도 마찰 요인으로 남는다 — "종결 = 리스크 소멸"이 아니다

## co-newbiz 매핑

- Brownfield 트랙(대상 기업 실사)은 confirmatory DD 단계에 대응 — S9 게이트의 "적용 체크리스트 전항목
  판정 + 필수 미충족 0건"은 confirmatory 단계의 표준 종료 조건(모든 워크스트림 검증 완료)과 동일한 원리.
- Greenfield 트랙(계획 실현가능성 검증)은 대상 기업이 없으므로 이 표준 프로세스와 1:1 대응하지 않음 —
  S5~S8 산출물(우리 계획)을 검증하는 것으로, 외부 대상 검증이 아닌 내부 가정 검증이 핵심 차이.
- S10 투자구조 설계는 "딜 조건 협상" 단계, S11 IC 심의는 "pre-closing 최종 확인"에 대응.
