# 리서치 노트 — 업종별 실사 체크리스트 맞춤화 표준 관행

> **언어**: [English](dd-checklist-tailoring-practice.md) · **한국어**

> 🌐 외부 참고 자료. 조사일: 2026-09-05. ADR-0099 맞춤 체크리스트(외부 검색 벤치마킹) 설계의 업계 관행 비교용.

## 표준 관행

1. **표준 체크리스트는 출발점이지 종착점이 아니다**: 핵심 원칙은 공통이지만 업종별로 고유한 리스크·
   규제·가치평가 변수가 있어, 실사는 대상 업종의 현실에 맞춰 조정되어야 한다 (Diligent, Chambers)
2. **업종별 초점 예시**: 기술(IP 소유권·데이터보안·SOC2/ISO27001 인증·리텐션), 제조(환경책임·설비
   상태·공급망), 헬스케어(라이선스·수가체계), 스타트업(cap table·소진율·계약직 개발 IP)
3. **다학제 팀 구성**: 재무·법무·운영·업종 전문성을 갖춘 다학제 팀이 체크리스트를 채워야 포괄적
   위험평가가 된다 — 단일 관점으로는 업종 특화 리스크를 놓친다
4. **항목별 필요성 재검토**: "이 항목이 이 특정 딜에 결정적인가?"를 표준 항목 각각에 묻는 방식으로
   커스터마이징하며, 자산 매수 vs 지분 매수 등 거래 구조에 따라서도 조정한다
5. **지속적 갱신**: 시장 상황·규제 변화·과거 실사에서 얻은 인사이트를 반영해 체크리스트를 정기
   갱신하는 것이 권장 관행 — 일회성 고정 문서가 아니다

## co-newbiz 매핑

- ADR-0099의 "표준 항목은 권위 원본으로 유지, 커스텀 항목은 augmenting"이라는 원칙은 업계 관행의
  "표준을 출발점으로 업종 리스크를 레이어링"과 정확히 일치.
- 커스텀 항목에 출처 신뢰도 등급(A/B/C)을 강제하는 설계는, 업계가 권고하는 "다학제 전문가 검증"을
  단일 담당자 대신 등급 체계로 대체 보완하는 co-newbiz 고유의 확장.
