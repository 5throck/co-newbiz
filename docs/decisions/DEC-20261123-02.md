### 2. Exception list (judgment-required — documented, not force-transformed)

1. **styles.css:682 `.notif-count` — `background: var(--accent); color: var(--bg)`.** The badge
   paints its glyphs in the PAGE background color over an accent fill (knockout idiom). Neither a
   forced `--fg` nor a bare exemption fits without a look. Ruling: implementer choice between
   (a) the role-correct `var(--accent-fg)` (the R2-C text-on-fill token; light #f6f7f9→#ffffff is
   imperceptible, dark theme both #0a0c10 — identical; the --accent-fg/--accent contrast pair is
   already ENFORCED) — recommended; or (b) keep with
   `/* design-token-exempt: knockout-badge (page-bg as ink on accent fill) */`. Either greens the
   line; the choice needs only a visual confirm, not a new ruling.
2. **The 131 bracket-utility findings are NOT exceptions.** They are a scanner defect (class C
   above); exempting or allowlisting correct code is rejected as laundering (DEC-20261122-02
   precedent). They are recorded here so the upstream request can cite exact counts.
3. **Charts are not an exception in this batch.** All 18 flow-graph.tsx findings are prose
   mentions; the SVG geometry (viewBox coordinates, NODE_W = 264-unit values) is unit-less numbers,
   not px literals, so no token substitution applies, and chart series colors already run through
   the ADR-0087 token-driven theme (`--chart-1..8` in styles.css, lib/echarts-theme.ts).
