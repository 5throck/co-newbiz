## Determination

1. **Row 0 determination — amend the existing spec.** All six items are
   completions of the registered `2026-11-08-committee-minutes-as-meeting-design`
   (same subsystem, same ADR-0196 doctrine); the design doc gains §9
   (2026-11-11); no new spec; the registry id stays stable and the entry goes
   back to `draft` while the batch is implemented.
2. **F1 is the only behavior change and is accepted as designed in §9.1.**
   The verified mechanism: the model emits the tail (the `committee.position`
   prompt requires it), `makeLlmCommitteeAgent` strips it at parse time
   (behavior unchanged since 60ac19f1, 2026-09-08), and the tail vanished from
   the RECORD when #845/#849 (d6321197, dde41253 — 2026-11-09/10) made real
   LLM seats reachable and removed the silent deterministic fallback whose
   inline-marked positions had masked the asymmetry. The fix restores design
   §2.5's own S2 contract ("keep them inside the position text's
   `position-meta` tail, which is already stored verbatim in `position_md`
   and re-parsed on read") by canonical re-serialization at the call site;
   deterministic minutes/agenda fallback quality is restored and the failure
   mode on an omitted tail is an honest per-seat degradation, never a
   fabricated verdict.
3. **F4 is a semantic choice, accepted.** The manifest join moves to the
   ADR-0180 resolution order; the observable consequence (manifest block,
   provenance line, and advisory section cite the same
   `market_sizing_version` even when `market_scope` disagrees with
   `industry_id`) is documented in §9.4 and is the point of the fix.
4. **F6 is a rewording, not an allowlisting.** Both strings keep their
   meaning; the kill-criteria title still names the responsible role
   (ADR-0186), matching the KO twin's plain-role pattern.
5. **F2/F3/F5 are mechanical** (type SSOT in deliberation.ts; a drift-guard
   unit test; an ellipsis marker) and carry no semantic risk beyond what §9
   states.
6. **Recorded out of scope:** `committee-session.parsePositionMeta` whitelists
   only the four legacy fields and `groupByRound` does not map
   `veto_dissent → vetoDissent` on the hybrid advance path — a pre-existing
   gap adjacent to F1's seam that needs its own ruling (§9.1).
