## Context

- Dev-sync step 3.8 (`scripts/archive-memory.ts`) moves memory files older than 7 days into `memory/archive/`.
- `.gitignore` carried a `memory/archive/` exclusion, so a file that moved into the archive dropped out of git tracking.
- On 2026-11-19 this broke for real: DEC-20261110-01 and DEC-20261111-02 failed the `validate-decisions` gate because their `knowledge_refs` pointed at memory files that were no longer in the checkout.
- `validate-decisions` checks referenced files for existence precisely so the ADR-0061 evidence chain survives a fresh clone; a gitignored archive defeats that guarantee.

## Decision

- Lift the `.gitignore` exclusion of `memory/archive/`; archived memory files are tracked in the repository.
- `.gitignore` is template-managed, so the change is recorded as a local patch with the marker `LOCAL-PATCH(upstream-request: U-20261119-001)`; upstream ticket U-20261119-001 has been filed.
- Archive files are small text (tens of KB), so the repository-size burden is negligible.

## Consequences

- `validate-decisions` knowledge_refs existence checks now hold on a fresh clone.
- The archive move in dev-sync step 3.8 no longer removes evidence from the repository; git sees it as a tracked move.
- Rejected alternatives are recorded above so the ruling is not reopened without new evidence.
