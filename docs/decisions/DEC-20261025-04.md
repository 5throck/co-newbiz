## Approver

- **Approved by**: pm — deferral ruling on the `--fs-lead` follow-up raised after PR #724 (inbox styles folded from 15px to the 14px floor); recorded by docs-writer on PM dispatch, 2026-10-25. No gate verdict, scope change, or new token ships under this record.

## Basis and limits

- **(a) Basis.** The Wave-U typography scale (`docs/designs/2026-10-08-wave-u-ux-overhaul-design.md` §Readability: base body 14px minimum, long-form 15–16px as guidance, not a token tier) plus the blocking design-lint token gate (`scripts/audit.ts` design-lint check; `scripts/design-lint.ts`) define the automated floor state. PR #724's fold of the inbox styles to 14px leaves the codebase floor-consistent with zero should-be-token findings, so the deferral costs nothing today.
- **(b) Reopen condition.** The lead tier is introduced only when a concrete long-form readability need is demonstrated (e.g. an audited screen where 14px body measurably fails readability); the request must arrive as a skill/scope change through PM triage, not as a literal reintroduction.
- **Limits.** This record changes no code and adds no token; it does not alter the 14px floor, the design-lint gate, or the Wave-U scale. If a lead tier is later adopted, it amends this ruling by supersession, never by silent addition.
