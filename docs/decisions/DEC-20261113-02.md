## Context

- Dev S1 re-analysis failed: every pipeline LLM call returned `LLM HTTP 400: Unsupported parameter:
  'max_tokens' is not supported with this model. Use 'max_completion_tokens' instead.` The dev
  config (repo-root .env, the SSOT since DEC-20261113-01) is provider `openai-compatible` against
  the `api.openai.com` host with model `gpt-6.1-terra` (key values not reproduced anywhere).
- `app/web-next/lib/llm.ts` `buildRequest` (:494) branches three ways: anthropic (:509, `max_tokens`
  — correct for the Anthropic Messages API), gemini (:539, `generationConfig.maxOutputTokens` —
  correct), else openai-compatible/custom (:548, `max_tokens` — the bug path). Both the JSON and
  streaming paths build their body through this one function (:139, :427), and 20+ consumer files
  only pass a `maxTokens` budget into `CallSpec` — the parameter-name decision is provably
  centralized, no caller hardcodes a request body.
- Production (.env.prod) runs provider `anthropic` via a z.ai anthropic-compatible endpoint —
  the anthropic branch is untouched by this ruling, so production behavior is value-neutral.
- The user approved the repair direction ("llm.ts code fix" — translated from the Korean instruction, 2026-11-13); PM dispatched this Row 0.

## Determination

1. **Row 0: non-exempt, design of record registered.** Wire-format change in the shared transport
   plus new retry/memoization behavior requires the full Design Gate chain before Rows 1+.
2. **Resolver + memoized probe, heuristic as accelerator, knob as override.** Order: knob →
   api.openai.com exact-host heuristic (auto) → `max_tokens` default with in-band 400-signature
   fallback memoized per provider|baseUrl|model. See design doc §3 for the contract and §5 for the
   alternatives table.
3. **Retry semantics refined, not broadened.** The ×4 budget multiplier stays bound to
   empty-response failures; an unsupported-parameter 400 resends once at the original budget with
   the corrected parameter name. The empty-response retry at llm.ts:135/:148 and the llm-json
   truncated detection (llm-json.ts:236) are unchanged.
4. **Budget default stays 1500, limitation documented.** OpenAI reasoning models count reasoning
   tokens inside `max_completion_tokens`; the ×4 empty-response retry is the existing mitigation.
   A model-aware budget floor is a registered follow-up that needs live evidence from
   gpt-6.1-terra before a number can be justified.
5. **env-check probe deferred.** The probe at scripts/co-newbiz/env-check.ts:138–141 hardcodes the
   Anthropic `/v1/messages` endpoint and `max_tokens: 8` regardless of provider — already the
   registered follow-up of the env-single-source design (§8.1); this batch does not touch it.
