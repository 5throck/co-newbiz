# Design: Resync leftover fixes — calibrate Windows temp dir + CI test steps (2026-09-20)

- **Spec ID**: 2026-09-20-resync-leftover-fixes
- **Date**: 2026-09-20
- **Status**: implemented
- **Source**: manual

## Problem

Two pre-upgrade fixes from the 2026-09-20 evening resync working tree never
landed in PR #387. They survived only inside the pre-upgrade stash
(`pre-upgrade-snapshot-20260920`):

1. `scripts/co-newbiz/calibrate.ts` wrote the correlation.py input file to a
   hard-coded `/tmp/calibrate-*.json` path. Windows has no `/tmp`, so the
   calibration case of `newbiz.ts` fails on Windows operator machines.
2. `.github/workflows/ci.yml` ran no test suites — the CI workflow executed
   only the documentation audit and the secret scan. Unit and script
   regressions could merge undetected.

## Decision

Recover both changes from the pre-upgrade stash and land them intentionally.
The remaining six stash entries are reviewed and deliberately discarded:
`.mcp.json` removal + its `.gitignore` addition (removes the project MCP
server configuration), `.gitleaks.toml` allowlist edits (unfinished policy
work on a template-managed file), README `cd` note, `next-env.d.ts` path
(regenerated by Next), and a single test timeout bump.

- `calibrate.ts` v1.0.0 → v1.1.0: write the input file into a private temp
  directory `mkdtempSync(join(tmpdir(), "co-newbiz-calibrate-"))` and remove
  the whole directory with `rmSync(..., { recursive: true, force: true })` in
  the existing finally block. `existsSync` stays for the venv check.
- `ci.yml`: add `Run unit tests` (`bun run test:unit`) and `Run script tests`
  (`bun run test:scripts`) steps after the audit step. Both package scripts
  exist since PR #387.
- `scripts/SCRIPTS.md` registry: calibrate.ts entry version 1.0.0 → 1.1.0
  with a change note; `docs/VERSION_MANIFEST.md` regenerated.
