# S8 브라운필드 인수 가격 — 외부 사례 기반 초기 투자 규모 (매출의 50% 가정 교체)

- Date: 2026-10-10
- Status: Implemented (사용자 요청, 2026-10-10 대화)
- ADR: `docs/adr/0143-s8-per-target-feasibility-target-axis.md` (실무 정합),
  ADR-0106(year-0 초기투자 도입)의 브라운필드 확장
- Related: design 2026-10-10-s8-brownfield-revenue-anchor-design (매출 앵커 — 이
  문서의 전제), design 2026-09-18-s8-business-case-evaluation (bc.* 어휘)

## 문제

매출 앵커 수정 후 남은 결함: year-0 초기 투자가 **year-1 매출의 50%**
(`INITIAL_INVESTMENT_RATIO = 0.5`, ADR-0106의 그린필드 설립 셋업 비율)로
모델링된다. 매출 389억(로보티즈 FY2025, DART)의 인수 대상을 195억에 사는
셈이라 IRR 65.4%라는 비현실적 수치가 나왔다. 실제 인수는 기업가치(EV)를
지불하는 거래이며, 사용자 지적대로 "외부 사례를 참고한 투자 규모"로
바꿔야 한다.

## 외부 사례 (조사: 2026-10-10)

| 사례 | 수치 | 매출 대비 |
|---|---|---|
| 삼성전자–레인보우로보틱스 (2023.12 계약, 2024 최대주주) | 지분 인수+유상증자 약 2,674억 (뉴스1 2024-12-31 등 다수 보도) | 당기 매출 152억 대비 최소 ~16× |
| 레인보우로보틱스 현재(2026) | 기업가치 약 2조 (톱데일리 2026-02-25; "2년새 가치 8배" 아시아투데이 2026-01-21) | 매출 341억 대비 ≈ 59× |
| 글로벌 로보틱스/자동화 M&A 컴프 | — | 2–6× EV/Revenue 밴드 (하드웨어 중심 저마진 1–3×, SW 결합형 5–10×) |

한계: 웹 검색 API 한도 소진으로 글로벌 컴프 밴드는 일반 지식 기준 밴드로
기록했고 개별 해외 거래 출처는 인용하지 못했다. 한국 전략적 휴머노이드
프리미엄(수십 배)과 글로벌 산업용 컴프(2–6×)의 괴리가 크므로, **단일
"정답 배수"가 아니라 기본값 + 사용자 확정 구조**가 유일하게 정직한 설계다.

## 결정

**매출 앵커가 있는 브라운필드 대상 케이스의 year-0 유출은 인수 기업가치다:
`인수가 = 대상 매출 × EV/Revenue 배수`.** 시나리오와 무선(가격은 한 번
협상된다 — 시나리오는 인수 후 실적만 바꾼다).

| 항목 | 규칙 |
|---|---|
| 기본 배수 | 3.0× — 글로벌 로보틱스 M&A 밴드 2–6×의 보수적 스크리닝 기준. 출처 라벨에 밴드 명시 |
| 사용자 확정 | `bc.acquisition_ev_revenue` (kind=user, 근거 필수) — 딜 특성 프리미엄(한국 전략적 인수 등)은 분석가가 확정 |
| 직접 노브 우선 | 사용자가 `bc.initial_investment_ratio`를 명시했으면 그 비율 모델이 이긴다 (투자 규모의 직접 제어) |
| 처분 가치(exit) | 회수 시점(H년)에 **진입과 동일 배수** × 최종년 매출로 처분 — 멀티플 확대 없음(보수). exit이 없으면 5년 창구 때문에 시장 배수 진입이 항상 NPV 음수로 나오는 지평선 왜곡이 생긴다 |
| 그린필드/앵커 없는 대상 | 기존 ADR-0106 비율 모델 그대로 (exit 없음) — 숫자·시드 불변 |

구현:

- **Python 엔진** (`python/sim_engine/engine.py`, `job_spec.py`): 신규 케이스
  드라이버 `exit_ev_revenue` (기본 0 = 기존 계약 그대로). MC 경로는
  반복마다 `+ revenue_H × 배수 / (1+r)^H`, 결정론적 경로는 마지막 연도
  플로우에 처분가치를 합산(base_npv·IRR·payback 일괄 반영).
- **TS 생성기** (`app/web-next/lib/business-case-generator.ts`):
  `CaseInputs.acquisition` + `initialInvestmentOf`/`exitEvRevenueOf` 통합
  접근자 — `runSeededSimulation`·`deterministicCashflows`·`buildS8JobSpec`
  (드라이버 `initial_investment`·`exit_ev_revenue`)·실행 프롬프트가 한
  곳에서 해석. note에 `acq_ev=3.00x; exit_ev=3.00x` 근거 스탬프.
- **파라미터** (`bc.acquisition_ev_revenue`): params GET/POST 라우트 +
  ParamsPanel(현재 해석값 행 + 확정 입력) — REQ-W6 어휘 패턴 그대로.

## 기간(회수 기간) 민감도 — "10~20년 DCF가 표준 아닌가" (2026-10-10 보강)

표준 기업가치 DCF는 10~20년 명시적 전망 + 영구가치(terminal value)를 쓴다.
이 모델은 다른 표준 구조를 쓴다: **5년 홀드 + 시장 배수 처분**(PE/M&A
언더라이팅 관행) — 처분가치(3.0× × 5년차 매출)가 곧 5년 이후 가치를
시장 가격으로 자본화한다. 즉 5년 창구가 가치를 '자르는' 게 아니다.

기간을 늘릴 때 수치가 어떻게 움직이는지(로보티즈 시장 기반, 결정론적
경로, 인수가 1,168억):

| 구조 | NPV | H년 매출 |
|---|---|---|
| 5년 홀드 + exit 3× (현행 기본) | 2,408억 | 1,496억 |
| 10년, 성장 40% 고정 | 11,970억 | 8,046억 |
| 20년, 성장 40% 고정 | 150,537억 | 232,735억 |
| 10년, 성장 40%→3% 선형 페이드 + exit | 2,782억 | 1,859억 |

- 성장률을 수렴시키지 않고 창구만 늘리면 NPV가 5배(10년)/63배(20년)로
  폭증한다 — 20년차 매출 23조는 시장 전체보다 큰 인공물이다. 현 모형은
  성장에 재투자 비용이 연동되지 않아(성장이 '공짜') 고성장을 길게
  복리하면 허수가 만들어진다. 누구도 40% CAGR을 10~20년간 인수가격에
  반영하지 않는다.
- 성장률 페이드(40%→말미 3%)를 넣은 10년 창구는 **2,782억 — 현행
  2,408억과 +16% 차이**다. 두 표준 구조(5년 홀드+exit vs 페이드 10년
  DCF)는 이론대로 대략 일치한다.

결론: 기간 연장 자체가 아니라 **성장률 비수렴 + 재투자 미연동**이 장기
창구를 불가능하게 만드는 병이다. 명시적 10년 창구를 원하면 페이드 곡선
(예: `bc.growth_terminal`, 선형 수렴) 도입이 선행 조건이다(후속 설계
후보). 현행 기본(5년 + exit 배수)은 그대로 둔다.

## 결정 추가: 이중 구조 교차검증 — 두 표준 구조의 병렬 계산·비교 (2026-10-10)

위 분석의 후속으로, 사용자 요청("둘 다 구현해서 비교")대로 **두 구조를
같은 케이스에서 동시에 계산해 나란히 보여준다.**

- **기본 구조(변경 없음)**: bc.horizon_years(기본 5년) 홀드 + 동일 배수
  처분 — 몬테카를로 p05/p50/p95·IRR. 게이트·킬 크라이테리아·권고가
  판정하는 1차 수치.
- **교차검증(페이드 DCF)**: 같은 드라이버로 결정론적 재평가 —
  `bc.fade_horizon_years`(기본 10년) 창구에서 케이스 성장률이
  `bc.growth_terminal`(기본 3%)까지 **선형 수렴**(2년차 = 케이스 성장률
  무페이드, H년차 = 말기 성장률), 마지막 해 동일 배수 처분. 분포가 아니라
  **구조**를 검증하므로 결정론적 경로만 계산한다.

구현:

- `fadedExitDcf(inputs, scenario, variant)` (`business-case-generator.ts`):
  인수 가격 케이스에만 적용(그린필드/폴백 → null). 동치성: 페이드 무효
  (말기 성장률 = 케이스 성장률) + 창구 = 기본 horizon이면 기본 구조의
  결정론적 NPV와 **정확히** 일치한다(테스트로 보장).
- note 기계판독 파편: `xcheck=fade-dcf; xcheck_horizon=10;
  xcheck_terminal_growth=0.0300; xcheck_fade_npv=<KRW-M>;
  xcheck_fade_irr=<ratio>` — UI가 파싱해 표시한다(REQ-W5-1 패턴).
- UI: 시나리오 매트릭스에 **"페이드 DCF p50"** 컬럼(단위 백만 원, 툴팁에
  구조·IRR 설명). 실행 로그 프롬프트에 구조 비교 문장 1행 추가.
- 파라미터: `bc.fade_horizon_years`, `bc.growth_terminal` — params
  GET/POST + ParamsPanel(해석값 행 2개 + 확정 입력 2개).

실측(휴머노이드 프로젝트 재생성, base p50):

| 대상 · 관점 | 기본(5년 홀드+exit) | 페이드 DCF(10년→3%) | 차이 |
|---|---|---|---|
| 로보티즈 · 시장 | 2,394억 / IRR 40.0% | 3,333억 / IRR 30.7% | +39% |
| 로보티즈 · 과거 | 554억 / IRR 20.0% | 794억 / IRR 17.8% | +43% |
| 레인보우로보틱스 · 시장 | 1,997억 / IRR 40.0% | 2,920억 / IRR 30.7% | +46% |
| 레인보우로보틱스 · 과거 | 1,912억 / IRR 39.7% | 2,878억 / IRR 30.5% | +50% |

해석: 두 구조가 +39~50% 범위에서 일치 — 3× exit 배수이 40%→3% 수렴
성장의 펀더멘털보다 다소 보수적이라는(즉, 배수를 올리면 기본 구조 값이
따라오는) 신호다. 이 괴리 폭 자체가 분석가에게 전달되는 정보다.



- **현행 유지 (매출 50%)** — 인수 대상에 적용하면 IRR 65% 등 비현실적
  과대 수익률로 모든 딜이 통과. 스크리닝 도구로서 무의미.
- **시장 시가 기준 동적 배수** (대상 상장주식 EV/Revenue 그대로 반영) —
  실시간 시가 데이터가 시스템에 없고, 인수 프리미엄·지분구조 반영 시
  확정적이지 않다. 대상별 거래 기대치는 분석가 확정 값으로 다룬다.
- **회수 기간 연장 (5년→10년)** — exit 대신 창구를 늘리면 고성장 가정의
  복리 인공물이 커지고, bc.horizon_years 사용자 파라미터와 충돌한다.
