# ADR-0034: Manual pilot precedes system development

**Status**: Accepted
**Date**: 2026-08-20
**Deciders**: pm, process-governance-manager

## Context

Process defects (an unexecutable step, a checklist item nobody can complete, a judgment criterion with no available data) are far cheaper to find before a schema exists to encode them wrongly.

## Decision

Stage 3 runs one real review end-to-end using only the regulation book, procedures, and checklists — no system. Two consecutive failed pilot completions halts the project's progression to system development and returns it to process design.

## Consequences

This is a hard project-level kill switch, distinct from a per-deal Kill Criteria — see design §10's project-level stop condition.
