# ADR-0182 - 시너지 4요소 관계도·탭 재배열·AI 추천·필요 역량 충족도 5팩터 확장·검토 확정 스냅샷

- Date: 2026-10-18

## Decision

1. **관계도 표시**: 시너지 상세 상단에 4요소 관계도(연계 시너지 후보 N건 → 우선 시너지 선별 M건 → 필요 역량 K건·보유율 → 시너지 점수 S점·확정 상태)를 렌더한다. 데이터는 기존 ctx에서 산출하고 신규 조회는 없다. 노트 클릭 시 해당 탭으로 이동한다.
2. **탭 재배열 (흐름 순서)**: `개요 | 연계 시너지 | 우선 시너지 영역 | 필요 역량 | 의사결정 | 출처·노트`. 필요 역량 탭은 우선 시너지 뒤로 이동한다(이전 배치 "개요와 연계 사이"를 대체 — 사용자 확정).
3. **AI 추천 완성**: 연계 시너지 탭에 "AI 영역 제안"(기존 영역 제외·신규 영역 초안 → 기존 추가 폼 프리필), 시너지 점수에 "AI 보정 제안"(규칙 팩터·우선 시너지·필요 역량 근거로 ±10 이내 보정값·사유 초안 → 점수 확인 폼 프리필). 둘 다 사람 개시 호출 전용(경계 #2), 저장은 기존 사람 경유 PUT/폼.
4. **필요 역량 충족도 5번째 팩터**: `capability_coverage` 팩터 추가 — 레지스터 보유율·필수 충족율을 0-100으로 산정(필수 가중 2). 가중치 재조정: 시장 매력도 0.30 · 산업·역량 교집합 0.25 · 재무 여력 0.15 · 기회-시장 일치도 0.10 · 필요 역량 충족도 0.20. 레지스터가 비면 팩터 자동 제외(미반영 명시), MIN_FACTORS 2 유지.
5. **검토 확정 스냅샷**: 3단계 검토 판단 필요 항목에 사람 확인 체크·짧은 사유를 추가하고, 확인 상태는 게이트 결정 기록의 부속 스냅샷(decision record에 저장)으로 남긴다. 신규 테이블 없음 — ADR-0153 최소주의 유지.

## Consequences

- 점수 산식이 4팩터에서 5팩터로 확장 — 기존 분석 재계산 시 점수가 달라질 수 있으며, payload에 scoreBreakdown을 저장한 분석은 당시 값 고정.
- 필요 역량 레지스터가 비면 충족도 팩터 자동 제외 — 4팩터만으로 계산됨을 근거 패널에 명시.
- S2의 앵커 단위 select는 제거 (S1 분석 단위 선언으로 통합).

## Addendum 2026-10-21 (decider, chat — "확인한 내용을 저장할 방안이 없는 듯 해")

§5의 확인 상태는 결정 기록 부속 스냅샷**만**으로는 검토 작업이 페이지 이동 시 소실된다. 확인 체크를 `review_claim_ack` 원장(migration 0165, append-only, entity·gate·claim별 최신 행이 현재 상태)에 **중간 저장**하고, 결정 기록은 기존대로 자체 스냅샷(`judgement_confirmations_json`)을 유지한다. 이로써 본 ADR의 "신규 테이블 없음" 조항을 수정한다(신규 테이블 1개). 또한 프로젝트 게이트 라우트가 `judgement_confirmations`를 저장하지 않던 누락을 기회 라우트와 동일하게 수정한다. 결정은 여전히 사람이며, 체크는 결정을 막지 않는다.
