# ADR-0140 — S7 재무 평가 DART 자동 초안(결정론적 루브릭 + 사람 확정)

- Date: 2026-09-16
- Status: accepted (implemented same day)
- Supersedes: ADR-0139 결정 3의 "빌트인 5항목" 고정 목록(나머지는 유지·강화)

## Context

S7 재무·기술 평가(ADR-0139)는 재무 빌트인 항목의 판정을 전부 사람 select로만
기록해 왔다. 그런데 판정에 쓰이는 숫자(매출·영업이익·당기순이익·부채총계·
자본총계 × 5개년)는 이미 DART 동기화(dart-financial-facts.ts, ADR-0116)로
fact_financial에 있고 deriveFinancialAnalysis(ADR-0093)가 추이·비율까지
결정론적으로 계산한다. 사용자 요청(2026-09-16): DART 재무정보가 확보된
후보는 재무 평가 초안을 자동으로 만들고, 기술적 평가가 완료되어야 종합
평가가 성립하므로 초안은 확정 전까지 자유롭게 고칠 수 있어야 한다. 단,
"판정은 항상 사람"(ADR-0139 경계)과 게이트 판정은 인간이라는 워크스페이스
원칙은 그대로 지켜야 한다. chk-target-screening의 스크리닝 판정 초안
(ADR-0118)이 이미 같은 문제를 "초안만 만들고 저장은 사람" 패턴으로 풀었다.

## Decision

1. **결정론적 루브릭 엔진을 만든다 — LLM을 쓰지 않는다**
   (`lib/brownfield-financial-rubric.ts`). 같은 facts·같은 임계값이면 항상
   같은 제안이 나와야 하고 근거 숫자가 note에 그대로 남아야 하기 때문.
   facts가 없거나 최소 연수(minYears) 미달이면 제안을 만들지 않고 이유만
   반환한다(날조 금지 — screening-draft와 같은 원칙).
2. **재무 빌트인을 4항목으로 확정하고 당기순이익 항목을 추가한다** —
   `revenue_5y` / `operating_profit_5y` / `net_income_5y`(신규 — 영업외
   손익·금융비용을 포함한 최종 수익성) / `debt_5y`. 시딩은 data_ref 단위로
   보강하므로 기존 오퍼튜니티에도 새 항목만 추가 시딩된다. 영업부문(세그먼트)은
   DART 미지원으로 계속 제외, 유동성 지표는 WANTED_ACCOUNTS에 유동자산·
   유동부채가 없어 계속 범위 밖.
3. **초안은 저장하지 않는다** — `POST .../targets/{id}/eval-draft`는 제안
   (pass/partial/fail + 지표 배지 + 근거 노트)만 반환하고 DB에 쓰지 않는다.
   사람이 select를 바꾸거나 "초안 저장"을 누를 때 기존 `PUT eval-state`
   (ADR-0139)로 확정되며 assessed_by는 항상 실제 사용자다. 이미 사람이 판정한
   항목은 초안 대상에서 제외한다. 기술 평가·커스텀 항목은 자동화 대상 밖.
4. **임계값은 항목별 루브릭으로 편집 가능하게 한다** — migration 0107로
   `brownfield_eval_criterion.rubric_json` 추가(NULL이면 코드 기본값).
   기본치: 매출 CAGR ≥+5%(부분충족 ≥0%), 영업이익 전 기간 흑자+최근
   영업이익률 ≥5%, 순이익 ≥3%, 부채비율 ≤200%(부분충족 ≤300%)·기간 상승
   ≤50p.p., 최소 데이터 3개년. PATCH eval-criteria로 재무 빌트인 항목만
   수정 가능하며 감사 로그를 남긴다.
5. **판정 규칙의 보수성** — 최근 연도 적자·부채비율 초과는 미충족, CAGR
   기점 ≤ 0은 성장률 대신 추이 방향으로 보수 판정, 자본잠식(부채비율 ≤ 0)은
   미충족. 애매한 경우는 부분충족으로 돌리고 사람이 조정한다.

## Alternatives considered

- **판정 자동 기록(사람 확인 없이)** — 기각. Short List 승격 조건이 "전 항목
  판정 완료"인데 자동 기록이 섞이면 판정 무결성이 무너지고 ADR-0139의
  "DART가 verdict를 쓰지 않는다" 경계·게이트 판정은 인간 원칙을 위반한다.
- **LLM 판정 초안(재분석 파이프라인 재사용)** — 기각. 숫자 판정은 결정론적
  규칙이 더 정확·재현 가능하고 비용이 없다. 웹 근거가 필요한 스크리닝
  (t-01~t-09)은 LLM 초안을 유지한다.
- **초안을 별도 테이블에 저장** — 기각. 저장되는 판정은 사람 확정본뿐이어야
  감사가 단순하다(screening-draft와 동일한 선택).

## Consequences

- 평가 탭 재무 카드에 "재무 판정 초안(DART)"·"초안 저장"·"임계값 편집"이
  붙고, 초안이 뜬 항목은 select·근거 노트 모두 확정 전 수정 가능하다.
- 임계값은 오퍼튜니티 단위(항목 공유)이므로 같은 Long List 후보끼리는 동일
  기준으로 비교된다. 업종 중앙값 등 상대 기준화는 시장관측 데이터와의
  연결이 성숙한 후속 범위.
- ADR-0139의 "5항목" 고정 목록은 이 ADR의 4항목으로 대체된다(경계·점수
  모델·게이트 무관성은 그대로).
