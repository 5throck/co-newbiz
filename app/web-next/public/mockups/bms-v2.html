  • 창조장기: 유지보수·SW 구독
    하드웨어 일회성 판매를 넘는 반복 수익 모델 신설
시장 진입 1단계 — 자사 라인 내부 적용 실증 → 2단계 — 국내 제조·물류 상업 판매 → 3단계 — 해외 확장 (검증 필요)
제거 1업계가 당연하게 여기는 요소를 버린다
감축 2업계 표준보다 줄인다
증대 1업계 기준보다 높인다
창조 2업계에 없는 것을 만든다

💡 배지(제거·감축·증대·창조)는 해당 항목이 블루오션 관점에서 어떻게 나아가야 하는지를 표시하며, 그 아래 회색 줄이 근거/방향입니다. 배지 개수는 ERRC 요약 스트립에서 한눈에 집계됩니다.

  • 고객 — 1차: 자사 제조·물류 라인(내부 수요) → 2차: 국내 제조·물류·휴먼캐어 기업(정부 민관 3조 원 투자·100만 대 보급 정책 수요 기반). 글로벌 외부 고객 확장은 검증 필요
  • 가치 제안 — 반도체·전장 부품 역량 기반의 관절 액추에이터·이족보행 플랫폼으로, 고령화·인건비 상승 속 비정형 작업을 수행하는 국산 휴머노이드 솔루션 제공. 후방·전방 시너지로 초기 검증~양산 단계 리스크 축소
  • 수익 모델 — 초기: 자사 라인 내부 적용으로 비용 절감 효과 실증 → 중기: 상업용 대당 $3만~10만 진입대 하드웨어 판매 + 핵심 부품 선공급(B2B 부품 매출) → 장기: 유지보수·소프트웨어 구독
  • 필요 역량 — 관절 감속기·프레임리스 모터 등 정밀 액추에이터 설계·양산 / 엣지 AI 반도체·온디바이스 컴퓨팅 / 이족보행 제어·안전 인증 SW(외부 확보 검토) / 파일럿 실증 체계 / 전략적 투자 실행 여력
  • 핵심 리스크 — 기술 미성숙·양산 지연, 시장 추정 산포($0.4B~$7.8B), 중국 가격 공세, 규제 반발, 미국 대비 기술 격차
  • 시나리오 전제 — 낙관: 국내 표준 플랫폼 선점 / 기본: 2026년 $3.20B 시장 단계적 진입, 부품 매출 초기 수익 / 비관: 양산 지연·가격 공세로 회수 불가

시나리오 전제 (낙관 / 기본 / 비관)

낙관

2026년 글로벌 $3.20B 시장에서 자사 라인 실증 후 국내 제조·물류 중심 단계적 상업 판매, 부품 매출이 초기 수익원

비관

기술 미성숙으로 양산 지연 + 중국 가격 공세·시장 축소(하단 $0.4B대) → 전략적 투자 회수 불가 수준 부진
