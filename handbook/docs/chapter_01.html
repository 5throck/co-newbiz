1장 플랫폼 개요와 핵심 개념

co-newbiz는 신규사업 제안을 12개 스테이지(S1~S12)로 구성된 단일 선형 체인으로 검토합니다. 각 스테이지는 AI 에이전트가 수행하는 활동(activity)과, 사람이 승인·보류·킬을 판정하는 게이트(gate)로 연결됩니다.

핵심 개념 4가지

개념 정의 자주 하는 오해
Stage ≠ Gate스테이지는 작업 구간, 게이트는 구간 사이의 판정 지점"S4를 통과했다"는 표현 — 실제로는 S4와 S5 사이의 게이트를 통과한 것
Opportunity ≠ Project기회(opportunity)는 S1~S7의 검토 대상, 프로젝트(project)는 S8~S12의 실행 대상. S8 직전 승격(promotion)으로 연결기회가 곧 프로젝트라는 생각 — 승격은 별도의 인간 승인 산출물을 필요로 한다
Artifact ≠ Decision산출물(리포트·채점표)은 근거이고, 결정(게이트 판정)은 인간 행위AI가 만든 권고 리포트를 결정처럼 취급하는 것
Track (GF/BF)S4에서 결정되는 진출 방식 — Greenfield(자체 역량 신설) / Brownfield(기존 기업·자산 결합)Brownfield = M&A. 실제로는 M&A·JV·전략적 투자·소수점 지분·파트너십·R&BD·CVC 중 하나

엔진이 넘지 않는 경계

플랫폼 전체를 관통하는 불변식은 다음과 같습니다. 화면에서 "엔진 권고 ≠ 채택", "결정은 인간 행위" 문구를 보면 모두 이 경계를 가리킵니다.

  • 경계 #2 — 엔진은 제안, 사람이 결정: 모든 게이트 결정은 사람의 클릭이며 감사 기록으로 남습니다.
  • 데이터 신뢰도가 RAG 등급을 상한 제한: B등급 프록시 체인은 숫자가 좋아 보여도 전체 평가를 Amber 이하로 제한합니다.
  • 게이트 승인·투자 결정은 인간 전용: 에이전트는 의결권이 없습니다.

역할과 화면 접근

역할 할 수 있는 일
analyst기회·프로젝트 수행 — 조사 실행, 산출물 작성, 게이트 결정 카드 조작
admin사용자·계정 관리, 시스템 설정. 딜 데이터는 ADR-0091에 따라 기본 비공개
