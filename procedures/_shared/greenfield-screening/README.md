# Procedure: Green Field Screening (Shared)

**Layer**: Procedure (mandatory — gate-blocking)

## Purpose

Screening-gate steps for Green Field (new establishment) review. Implements the two-stage site-scoring model fixed in meeting M6: a hard pre-filter (step 2) followed by a weighted score among survivors (step 3) — these are sequential stages, not competing checks (meeting M8 D-M8-1 sequencing clarification).

## What This Procedure Owns

Which agent runs at which step and in what order. The *how* — infrastructure lead-time estimation methodology, incentive NPV discounting — lives in the referenced skills (`site-infrastructure-assessment`, `regional-incentive-sourcing`), not here.

## Kill Criteria

`kill_criteria` in `schema.yaml` is authoritative. The headline case (wastewater capacity checked before power, per design §8.7) is enforced structurally in step 2 as an exclusion, not a scoring penalty.
