# 01. WACC 산정 및 Hurdle Rate 결정

> 절차 근거: `procedures/_shared/brownfield-pre-fs/schema.yaml` step 1 (agent: valuation-agent, skill: `wacc-input-session`) — S4 `03-deal-shape-initial.md` §3에서 "미수행"으로 이월된 항목. 방법론: `skills/wacc-input-session/SKILL.md` **CAPM-component 모드**.
> 단위: 모든 금액은 **억원(KRW 100M)**. `[가정]` 태그가 붙은 값은 로보틱스레인보우(가상 비상장기업) 관련 미검증 가정치다.

## 0. 중대한 절차적 경고 — `kind='user'` 미충족

`wacc-input-session` SKILL.md Execution Step 3–5는 WACC와 hurdle IRR이 **`kind='user'`(인간이 명시적으로 확인)**여야 FS 게이트가 열린다고 규정한다. 본 세션은 AI 단독 산정이므로 두 값 모두 현재 **`kind='derived'`/`'assumed'` 혼합 상태**이며, `kind='user'`가 아니다.

- 결과: Pre-FS kill criterion **`wacc_hurdle_still_assumed` (ADR-0064, kill #5/#6)이 아직 무장 해제되지 않았다.**
- 해소 조건: 인간 승인권자(valuation-agent 디스패치 하의 담당 임원)가 아래 §4 최종 수치를 명시적으로 확인하고 `bun scripts/co-newbiz/newbiz.ts assume --run <run_id> --key wacc --kind user --value 0.130` 및 `--key hurdle_irr --kind user --value 0.150`으로 등록해야 한다. **키 이름은 정확히 `wacc`, `hurdle_irr`** (SKILL.md "Key-name discipline" — `WACC`/`discount_rate` 변형 금지).
- 본 문서는 그 확인 세션에 제출할 **후보 수치와 산출 근거**를 제공하는 것이며, 확인 자체를 대신하지 않는다(Non-Negotiable Boundary #2).

## 1. 입력 모드 선택

`wacc-input-session` 2개 모드 중 **CAPM-component 모드**를 채택한다. 사유: 대상기업(로보틱스레인보우)이 비상장이라 시장 관측 WACC이 존재하지 않으므로 direct 입력이 불가능하고, 삼성전자 전사 WACC을 그대로 쓰면 사업위험이 전혀 다른 자회사에 모회사 자본비용을 잘못 적용하는 고전적 오류가 된다.

## 3. 계산 (재현 가능)

| 단계 | 산식 | 계산 | 결과 |
|---|---|---|---:|
| ① 차입베타 | `βL = βu × (1 + (1-t) × D/E)` | `1.35 × (1 + 0.78 × 0.20)` = 1.35 × 1.1560 | **1.5606** |
| ② 자기자본비용 | `Ke = Rf + βL × ERP` | `3.35% + 1.5606 × 6.30%` = 3.35% + 9.83% | **13.18%** |
| ③ 자본구성비 | `We = 1/(1+D/E)`, `Wd = (D/E)/(1+D/E)` | `1/1.20`, `0.20/1.20` | **We 83.33% / Wd 16.67%** |
| ④ 세후 타인자본비용 | `Kd × (1-t)` | `5.50% × 0.78` | **4.29%** |
| ⑤ 기본 WACC | `We×Ke + Wd×Kd(1-t)` | `0.8333×13.18% + 0.1667×4.29%` = 10.98% + 0.72% | **11.70%** |
| ⑥ 규모프리미엄 가산 | `⑤ + 1.50%` | `11.70% + 1.50%` | **13.20%** |
| ⑦ 확정 WACC(반올림) | — | 13.20% → 소수 첫째자리 | **13.0%** |

## 4. Hurdle Rate (기준수익률) 결정

| 단계 | 값 | 근거 |
|---|---:|---|
| WACC (자본비용 하한) | 13.0% | §3 |
| 전략적 리스크 스프레드 | +2.0% **[가정]** | 실행리스크(PMI, 인증 이전가능성 미확인, 시너지 3/4건 `assumed` — S3 `02-synergy-analysis.md` §4) 대비 요구 초과수익 |
| **Hurdle IRR (제안)** | **15.0%** | WACC + 200bp |

- **Kill 기준과의 연결**: `docs/process-flow.md` Gate:FS의 Kill 기준은 "기준 수익률 미달이 **기본 시나리오에서** 확인된다"이다. 즉 판정 대상은 Base 시나리오의 IRR vs 15.0%다 — §04 문서 §4에서 적용한다.
- Hurdle을 WACC과 동일하게(13.0%) 두는 대안도 가능하나, 그 경우 실행리스크가 요구수익률에 전혀 반영되지 않고 오직 현금흐름 가정에만 반영되어 이중 보수화 또는 과소 보수화를 통제하기 어렵다. 본 세션은 **할인율에 리스크를 싣고 현금흐름은 기대치(mean-expectation) 기준으로 유지**하는 방식을 택했으며, 이 선택 자체를 방법론 결정으로 기록한다.

## 5. Known Limitations

1. **`kind='user'` 미충족** — §0. 이 상태로는 FS 게이트가 절차적으로 열리지 않는다. 가장 중대한 미해결 항목.
2. **Rf 3.35%의 시점 불명** — 제3자 밸류에이션 사이트가 제시한 값이며 조회 기준일이 명시되지 않았다. 별도로 investing.com 한국 10년물을 조회했으나 반환된 페이지의 최종 갱신일이 2024-08-28로 표시되어(수익률 4.274%) 현재 시점 데이터로 신뢰할 수 없다고 판단, 채택하지 않았다. **Rf는 한국은행 ECOS 또는 금융투자협회 채권정보센터에서 2026-08월 기준 국고채 5년/10년물로 재확인 필요** — Rf 100bp 변동 시 WACC은 약 +83bp 변동(We×βL 경로 제외, Ke 직접효과 기준 +156bp)한다.
3. **βu 1.35는 삼각측량되지 않은 단일 판단치** — `skills/expert-interview` 원칙상 `derived`로 격상 불가, `assumed` 유지. DART 상장 로봇기업 피어그룹(예: 레인보우로보틱스, 두산로보틱스, 에스비비테크 등 실존 상장사) 회귀로 정식 도출해야 하나 본 세션은 DART API 키 부재로 미실시(§6).
4. **DART 실시간 조회 미완료** — 본 device_bash 환경에 `DART_API_KEY` 미설정(`k-dart` SKILL.md Execution Step 1의 전제 미충족). 삼성전자 재무제표·베타 원자료를 DART에서 직접 확인하지 못했고, 대신 공개 밸류에이션 사이트의 2차 가공치를 사용했다. **S1 요약에서 이미 기록된 동일 한계가 S5에서도 해소되지 않았다.**
5. 규모프리미엄 1.50%는 학술적 근거(Ibbotson/Duff&Phelps size premia)를 직접 인용하지 않은 관행적 가산치다.
