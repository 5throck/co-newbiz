# Gate Agent Skill Output Description
1 Entity IC legal-counsel legal-due-diligence formation_readiness_check

Formation readiness per checklists/entity-formation-checklist.yaml pre-incorporation items (ef-01..ef-04) — jurisdiction/entity type with documented tax/regulatory rationale, name and trademark clearance, share structure and directors/officers, parent board/GM resolutions authorizing formation, funding, and IP contribution. Nothing files until the readiness check confirms every pre-incorporation item.
2 Entity IC legal-counsel k-law statutory_filing_record

Charter filed, registered capital paid in, organizational documents executed, statutory registrations (tax, employer, licenses, foreign-investment filings), banking/insurance/audit opened, statutory books established — per chk-entity-formation formation-and-legal-wiring items. Where a company split (물적분할/인적분할) is the route: Commercial Act art. 527-2 shareholders' special resolution and art. 527-5 creditor-protection procedure (individual notice + public notice, >=1-month objection window) — verify against the current KLRI statute text before enforcement use.
3 Entity IC legal-counsel certification-transferability certification_transferability_check

Permits and certifications for the NEW entity classified as transfer / consent-required / re-issue — a permit lets you operate, a certification lets you sell (boundary #5); the classification feeds the compliance calendar. Confirms against the issuing body's own rules; inference disallowed.
4 Entity IC hr-integration-agent org-readiness-assessment people_transfer_record

People transfer into the entity — new employment agreements + PIIA per employee/contractor, secondment or transfer per applicable consent rules. Korea: employment succession on business transfer (영업양도) is judicial doctrine (Supreme Court 2000다8448 line), not statute — the individual-consent path is the safe practice; verify with counsel before enforcement use.
5 Entity IC process-governance-manager stage-gate-governance gate_pass_record

Completion confirm — every chk-entity-formation item evidenced in the entity data room, IP assignment chain closed (parent background IP + team work, written assignment/license), governance baseline set (first board minutes, delegated-authority matrix, compliance calendar). For joint origin additionally verify the JV addendum items (ef-13.. : board 5-9 with deadlock design, reserved matters, deadlock ladder, exit clauses, one-voice management, firewall where parents compete) — cross-ref the jv-structuring skill, which owns the how.
