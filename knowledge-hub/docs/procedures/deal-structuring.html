단계

# 게이트 에이전트 스킬 산출물 설명
1 DD brownfield-agent investment-vehicle-structuring deal_structure_review

Mature the deal-structure hypothesis: settle the vehicle (direct / SPC / holdco / internal_venture_spinoff / jv), the asset-or-stock form, the stake type, and the primary/secondary instrument mix; record the ADR-0045 four mandatory axis notes — tax structure, liability isolation, financing leverage, exit structure — each grounded in DD findings where they bear (contingent liabilities -> liability isolation; withholding and deal-tax posture -> tax structure; acquisition-finance capacity -> financing leverage; staged exit or trade-sale path -> exit structure). Record the rationale (mandatory) via db/repositories/deal-structure-hypothesis.repository.ts; a structure hypothesis without its rationale is rejected at the write layer.
2 DD brownfield-agent investment-vehicle-structuring four_axis_review_completion

Human-reviewer completion of the four-axis review — a deliberate, attributable act (completeFourAxisReview) that REQUIRES a deal_structure_review artifact reference; the completion is refused twice (no artifact ref, or already-completed hypothesis) rather than silently overwritten. The audit_log entry (four_axis_review_completed) is the review's evidence trail.
3 DD valuation-agent financing-plan-review financing_sources_uses_plan

Assemble the financing plan (sources & uses, migration 0075) — every funding line (equity commitment, acquisition debt, parent loans, incentive proceeds) on the sources side and every deployment line (purchase price, fees, working-capital injection, reserve) on the uses side, in KRW 백만원 (the ADR-0061 unit convention). Certainty of funds is evidenced, never assumed: commitment papers or internal-funds approvals are referenced in the note column per skills/financing-plan-review. The S10 completion predicate requires sources == uses > 0 — an unbalanced plan blocks stage exit the same way an unproven structure does.

산출물

  • deal_structure_review (four-axis complete, artifact-referenced)
  • financing_sources_uses_plan (balanced)
