# Gate Agent Skill Output Description
1 Pre-FS greenfield-agent greenfield-feasibility pre_feasibility_self_check

GF-internal pre-feasibility gate BEFORE FS opens: a pure internal venture (no external counterparty — ADR-0047 origin axis) must show (a) market evidence via a proxy-chain demand estimate (cross-ref proxy-industry-chain; chain reliability caps downstream confidence), (b) technical feasibility, and (c) right-to-win PROOF, not hypothesis — the Cooper Gate 2-to-3 escalation: right-to-win may be hypothesized at Screening but must be evidenced before the first major resource commitment. Not applicable (skip) for external-origin Green Field, where the counterparty's own evidence carries the feasibility case. An UNCLASSIFIED project does not skip this gate — unassessed origin applies the step by default (fail-closed).
2 Pre-FS valuation-agent wacc-input-session wacc_hurdle_confirmed

WACC/hurdle IRR moved from assumption.kind='assumed' to 'user' — hard precondition before FS opens (meeting M1). FS cannot proceed on a provisional discount rate.
3 Pre-FS greenfield-agent site-infrastructure-assessment infra_lead_time_cost_estimate

Infrastructure lead-time and cost estimate for the pre-filtered site shortlist from Screening.
4 Pre-FS greenfield-agent regional-incentive-sourcing incentive_npv_site_comparison

Incentive package converted to NPV, compared against infra capex and logistics cost on the same table per site (design §4-7, meeting M6 D-M6-3) — never listed as a separate figure from the cost side.
5 Pre-FS certification-agent permit-pathway-mapping certification_transferability_check

Confirm certification transferability where load-bearing to the thesis — only relevant if the site plan depends on an existing certified operation nearby or a certified partner; otherwise mark not-applicable.
5.5 Pre-FS certification-agent certification-roadmap certification_roadmap_map

Required-certification gap map with dependency DAG — sell-side access requirements tracked separately from permits (graph-pilot wiring, backfill-report §4.1).
6 Pre-FS process-governance-manager stage-gate-governance gate_pass_record

Confirm Pre-FS deliverables complete; open FS.
