# Gate Agent Skill Output Description
1 Screening financial-analyst historical-financial-analysis company_profile_financials

DART financial-statement ingest (3 business years, latest complete year first). The corp_code is resolved through the k-dart v2.1.0 fallback chain (24h-TTL bulk cache -> bulk retry -> web fallback with company.json cross-validation) and ONLY a cross-validated code is persisted on the company record — a code that fails name match is discarded and the step proceeds as 비상장 (research-based). Consolidated (CFS) statements with separate (BFS) fallback; account alias normalization applied.
2 Screening market-intelligence-agent company-intelligence company_profile_research_pack

External research pack — analyst reports, industry trends, and business performance excerpts (Tavily web research, up to 12 deduplicated sources). Every excerpt carries title/url/snippet provenance; the pack is the evidence base for the assessment step and is preserved in the profile version regardless of LLM success or failure.
3 Screening financial-analyst historical-financial-analysis company_profile_assessment

LLM strengths/weaknesses/opportunities/threats (SWOT)/business assessment grounded in the research pack and DART financials, with per-item source citations ([n]). On LLM failure the step stores a DEGRADED result: the failure reason is recorded (degraded flag), the fallback text reflects the actual situation (research count kept — never the misleading "research not configured" phrasing when sources exist), and the UI surfaces a 부분 분석(폴백) — 재분석 권장 chip.
4 Screening financial-analyst competitive-intelligence company_profile_competitive

LLM competitive positioning — main competitors with one-sentence sourced notes and a positioning assessment. Failure records a degraded note and NEVER blocks the version save (ADR-0093).
5 Screening financial-analyst historical-financial-analysis company_profile_synthesis

Deterministic synthesis (no LLM): financial ratios and YoY trends derived from the DART accounts; industry linkage matching each industryExposure entry to md_industry and its latest completed S1 market matrix (anchor total, bottom-up CAGR, external-forecast gap, qualitative factors); per-section confidence grades assigned from each section's evidence class; a verification ledger (confirmed / could_not_verify / needs_judgement — silence is never read as approval); and the RAG cap recommendation (analyst-confirmed state required before green — ADR-0093 adopting the ADR-0092 decision-6 S1 standard).
6 Screening process-governance-manager stage-gate-governance company_profile_version

Append-only version accumulation (company_profile_version, ADR-0005 run-versioning pattern) — re-analysis lands version N+1; prior versions are preserved so decisions can cite the exact profile version. Includes the synergy matrix derivation across affiliates (industry-exposure overlap) as a read-only by-product of the latest versions.
