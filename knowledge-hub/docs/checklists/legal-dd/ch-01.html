필수(mandatory) 항목은 활성 waiver 없이는 게이트를 통과할 수 없습니다. 권장 항목의 부재는 사유 진술로 충분합니다. 권위 원본은 저장소의 YAML입니다.

ID 항목 등급
ldd-01 법인 적격성 확인 (Good Standing) — 대상 및 모든 자회사의 정관·이사회 의사록 3개년 검토 필수
ldd-02 자본구조 재구성 (Cap Table) — 주식종류별 승인/발행 주수, 옵션·워런트·전환사채의 귀속·만기 목록 필수
ldd-03 주주 의결권·동의 요건 식별 — 양도제한·우선매수권·ROFR/태그얼롱/드래그얼롱 매핑 필수
ldd-04 계약 체결 권한 검증 (Signing Authority) — 대상·자회사를 구속할 수 있는 자를 명시 필수
ldd-05 차입·리파이낸싱·보증 제한 매핑 — 기업방어책(이사회 분산 등) 존재 시 식별 필수
ldd-06 상위 20개 고객·공급 계약의 지배권 변경(CoC)·양도금지 조항 스캔 — 통지기간·동의요건·해지 결과 기록, 독점·MFN·최소물량 커밋 캡처 필수
ldd-07 자산거래 vs 주식거래 양도 구분 — 동의가 필요한 계약과 자동 승계 계약 구분 필수
ldd-08 Close 시 동의·재융자가 필요한 대출·담보 문서 플래그 필수
ldd-09 계속·예고 소송·중재·규제조사 목록화 — 노출 추정액·충당금 적정성, 판결·집행·파산 검색 포함 필수
ldd-10 IP 인벤토리 완료 (특허·상표·저작권·도메인·영업비밀) + 발명자-회사 귀속 연계 검증 필수
ldd-11 In/Out 라이선스 검토 — 독점성·서브라이선스·양도 가능성·CoC 트리거 필수
ldd-12 IP 담보권·부담 검색, 유지·갱신료 납부 확인, 진행·예고 IP 분쟁 목록화 필수
ldd-13 임직원·컨트랙터 PIIA(발명 양도+비밀유지계약) 서명 확인 — 전원 이행 여부 필수
ldd-14 노조·퇴직연금 (해당 시) — CBA 승계조항·분쟁 잔여·만기 vs 딜 일정 확인, 노출 정량화 (없으면 not-applicable + 사유) 필수
ldd-15 사업 인허가별 이전 분류 명시 — 자동 승계 / 동의 필요 / 재발급 (certification-transferability 판단의 법적 근거) 필수
ldd-16 환경 통지·사전 토지조사·오염 이력 확보 필수
ldd-17 부동산 소유권·임차권 검증 (보유·임차 지분) — 임대차 CoC 조항 확인 필수
ldd-18 개인정보 보호 검토 — 처리방침·침해 기록·국외 이전 적법 근거 필수
ldd-19 부정방지(anti-bribery) 통제 테스트 + 상대방·실소유자(UBO) 제재 스크리닝 필수
ldd-20 세무 신고 현재성 확인 — 진행 중 세무조사·과세 예고 식별 필수
ldd-21 발견사항 대장(RAG 등급) 작성 — red=구조적/시정 필요, amber=보증·면책, green=수용 → SPA 보호·밸류에이션 조정(dd-to-valuation-bridge) 투입 필수
ldd-22 한국 유의사항 (한국 근로자 + 영업양도 경로 검토 시) — 영업양도 근로자 승계는 판례 확립(대법원 2000다8448 계열), 개별 동의가 안전 관행. 현행 법령·한국 변호사 확인 필요 — 선택 권장
